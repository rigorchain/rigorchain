# Software Verification and Distribution Policy

RIGOR is an independent open-source software project.

Official releases do not require Apple or Microsoft platform approval, code signing, or notarization.

This does not mean that RIGOR abandons software security or release responsibility. The project remains responsible for source-code review, testing, dependency integrity, and addressing identified security issues.

Users are free to inspect the source code, build independently, verify published checksums, or use official binaries at their own discretion.

RIGOR does not require users or maintainers to rely on platform-issued identities as the basis of software trust.

**We do not require platform approval. We provide verifiable software.**

Trust should come from verification, not identity.
